sip-and-sort딸기우유 한 모금 마시는 사이에, 협업 메일 정리 끝!

본인의 Google 계정과 이름(활동명)을 연결하면, 협업 제안 메일을 분류하고 답장 초안을 만들어 둡니다.

이 페이지는 내 PC(127.0.0.1)에서만 열립니다. 입력한 값은 이 PC의 파일에만 저장되며, 이 프로그램은 메일을 절대 자동 발송하지 않습니다.

1 내 Google OAuth 클라이언트 등록 확인 중

이 저장소에는 어떤 API 키도 들어 있지 않습니다. 각자 본인의 Google Cloud 프로젝트에서 발급한 credentials.json을 등록해야 합니다.

credentials.json 발급 방법
  1. Google Cloud Console에서 새 프로젝트를 만듭니다.
  2. [API 및 서비스] → [라이브러리]에서 Gmail API를 검색해 [사용]을 누릅니다.
  3. [OAuth 동의 화면]에서 사용자 유형 외부를 선택하고, 앱 이름·이메일을 입력합니다. [테스트 사용자]에 본인 Gmail 주소를 추가합니다.
  4. [사용자 인증 정보] → [사용자 인증 정보 만들기] → [OAuth 클라이언트 ID] → 애플리케이션 유형 데스크톱 앱을 선택해 만듭니다.
  5. [JSON 다운로드]로 받은 파일을 아래에서 선택합니다.
✓ 등록 완료 — 이 PC에 저장되어 있어 다시 등록할 필요가 없습니다.

2 이름(활동명)과 답장 문구 확인 중

입력한 이름은 답장 초안의 인사말과 서명에 {activity_name} 자리로 들어갑니다.

답장 문구 (A · B · C)

사용 가능한 자리표시자: {activity_name} 내 이름, {contact_name} 상대 담당자 이름, {original_subject} 받은 메일 제목. 알 수 없는 값은 초안에 [ ]로 남습니다.

3 Gmail 연결 확인 중

버튼을 누르면 새 탭에서 Google 로그인 화면이 열려요.

"액세스 차단됨 … 403 오류: access_denied"

  1. Google Cloud Console → Google 인증 플랫폼 → 대상으로 가요.
  2. 테스트 사용자 → + Add users에 로그인할 Gmail 주소를 추가하고 저장해요.
  3. 1~2분 뒤 여기서 [Gmail 연결하기]를 다시 눌러요.

"Google에서 확인하지 않은 앱" — 본인이 만든 앱이라 괜찮아요. [고급] → [(앱 이름)(으)로 이동]을 누르세요.

로그인 탭이 안 열려요 — 아래에 나타나는 [Google 로그인 열기] 버튼을 눌러 주세요.

Google 로그인 열기 새 탭에서 로그인·권한 허용을 마치면 이 페이지가 자동으로 '연결됨'으로 바뀝니다. (5분 제한)

4 메일 정리하기

미리 보기는 아무것도 바꾸지 않고 결과만 보여줍니다. 지금 정리하기는 Gmail에 라벨을 붙이고 답장 초안을 임시보관함에 저장합니다. (메일은 발송되지 않습니다)
